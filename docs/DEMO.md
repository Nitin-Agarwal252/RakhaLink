# Demo guide

## What you will see (about four minutes)
1. The problem and one verified statistic.
2. **Medical SOS** on the phone: the alert appears on the Responder Console and an SMS reaches a team phone.
3. **Accept** on the console, then mark **On the way** and **Arrived**: the rider's timeline updates with each real step.
4. **Simulate crash:** alarm countdown (20 s), then an automatic accident alert to a hospital and the police.
5. **Ignore an alert:** it escalates to the next-nearest responder.
6. **Airplane mode:** Morse SOS, the alert is queued, then delivered when signal returns.

## What is real and what is simulated
| Part | Status |
|---|---|
| Responder locations | Real (OpenStreetMap) |
| Responder phone numbers | Demo numbers owned by the team |
| Responder network on the console | Simulated and labelled |
| SMS and voice | Real to team phones, or labelled SIMULATED DISPATCH |
| Crash detection | Prototype heuristic. The demo uses a simulate button plus replayed traces |
| Location in the demo | Preset locations, because GPS is unreliable indoors |
