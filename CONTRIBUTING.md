# Contributing

This project is being built live at a hackathon. Until the event ends, only team members commit.

- One folder per person: `server/`, `mobile/`, `web/`, `docs/`.
- Small commits, clear messages (`feat:`, `fix:`, `docs:`).
- Never commit secrets. Use `.env` locally and keep `.env.example` names-only.
- Never test against real emergency numbers or real responders. Use `DEMO_MODE=true`.
